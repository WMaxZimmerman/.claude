#+title: Python house rules (PY)

Read with =common.org=, which applies here as well. Most entries are lifted from what the =mz-=
Python agents state, keeping the severity the agent states, or the one Max set where the agent
states none. Ids are never reused.

* Scope

Python code in any repo: a FastAPI/SQLModel service (routes, services, schemas, models — FastAPI,
Pydantic, SQLModel), a shared Python package, or a plain Python tool or CLI (=*.py=,
=pyproject.toml=); the tests for any of these; and Alembic migration modules.

* Calibration

- Apply to new or touched code the change wrote, per =common.org= Calibration. A long-standing
  pattern across an application is drift, surfaced once at the top of a review and filed as a
  =tech-debt= issue, not graded per file.
- Severities here override =mz-python-reviewer='s default for the same pattern.
- *Code shape.* An entry whose =Applies to= names a FastAPI/SQLModel service, or a tool or CLI,
  applies only to code of that shape, as =mz-python-reviewer= settles it from the repo contract or
  the code.
- *Route and service shape.* The route and service entries under Layering (PY-004 to PY-012) state
  the default — =schemas/<feature>.py=, a concrete =Sql<Thing>Repo= per feature with no =Protocol=
  or ABC over it, services returning the response schema — for a service that established no
  route/service shape of its own. Where the service's canonical route/service pair or its existing
  features established another shape, grade against that one: a change that follows it is not a
  finding, and a change that departs from it is, at the entry's severity.

* Layering

** PY-001 — A request or response model defined inside a =services/= package

- *Severity:* Smell
- *Applies to:* new or touched code
- *Rule:* Request and response models live in the API's schemas package
  (=app/schemas/<feature>.py=). A model the change defines inside a =services/= package — copying
  an older service-package shape — is the finding. A service module may re-export a schema; it
  does not define one.
- *Not a finding:* an existing instance of the older shape, including a service module that only
  re-exports from the schemas package for backwards compatibility. Neither is the example to copy.
- *Precedent:* none yet

** PY-004 — A join, filtered list, subquery, or pagination written inline in a service or route

- *Severity:* Smell
- *Applies to:* new or touched code in a FastAPI/SQLModel service
- *Rule:* A multi-table join, filtered list query, subquery, or pagination written inline in a
  service or route. Fix: a named method on the feature's repository (=Sql<Thing>Repo= by default;
  Calibration).
- *Not a finding:* a plain =db.get(Model, id)= + mutate + =add= + commit in a service — the house
  write path.
- *Precedent:* none yet

* Comments

** PY-003 — CM-003 in Python constructs, including docstrings

- *Severity:* Smell
- *Applies to:* new or touched code only, production and test code
- *Rule:* CM-003 applies — explanatory =#= lines, and docstrings on a module, class, function, or
  method, are both comments here. Recommend a more descriptive name or extracting a small
  well-named function, with design rationale moved to the pull-request description or the issue.
  In an Alembic migration, the content Alembic generates stays exactly as Alembic writes it: a line
  added to its header, or a generated line removed or reworded, is the finding.
- *Not a finding:* two carve-outs, and no others. First, a tooling directive — a =#= line that
  instructs a tool, such as =# noqa=, =# type: ignore=, or =# pyright:=, or an interpreter
  directive: a module's first-line =#!/usr/bin/env python3=, or an encoding declaration on the
  first or second line (=# -*- coding: utf-8 -*-=, =# coding: utf-8=,
  ~# vim: set fileencoding=utf-8 :~) — is not a comment for this rule; whether the warning a
  directive suppresses was justified is graded on its own, not under CM-003.
  Second, Alembic-generated migration content: the module docstring from the =script.py.mako=
  template (message, =Revision ID=, =Revises=, =Create Date=), the
  =# revision identifiers, used by Alembic.= comment, and the command-block marker comments
  autogenerate writes around the operations. A fact an operator needs goes in the pull-request
  description, not the file. Every other docstring or comment hand-written into a migration,
  inside =upgrade()= and =downgrade()= included, is a finding.
- *Precedent:* none yet

** PY-084 — A docstring or comment the change made false or stale, left on the function or class it modified

- *Severity:* Smell
- *Applies to:* touched functions, methods, and classes only, production and test code
- *Rule:* A pre-existing docstring or =#= comment on a function, method, or class the change
  modifies, which the change makes false or stale — a parameter renamed or removed but still
  described, a docstring describing behaviour the code no longer has. The line predates the change,
  but the change made it false, so it is the change's finding, not pre-existing drift. Fix: delete
  it (PY-003; CM-003). Rewriting it to match writes a new docstring or comment, which PY-003 flags.
- *Not a finding:* A docstring or comment on a function, method, or class the change does not
  modify — drift per CM-005. One on a modified function, method, or class that the change leaves
  true — PY-003's apply-to-new calibration holds, and the change need not remove it. The content
  PY-003 carves out: tooling directives and Alembic-generated migration content.
- *Precedent:* none yet

** PY-068 — A test that reaches a live host or a real binary without a mock or marker

- *Severity:* Bug
- *Applies to:* new or touched test code
- *Rule:* A test that would issue a real HTTP request or shell out to a real binary without a mock
  or the repo's integration marker. HTTP is mocked by default with the library the suite already
  uses; =subprocess.run= is mocked by default, and the real binary runs only under the integration
  marker. A unit test does not silently require a container or an external binary.
- *Not a finding:* a test under the repo's integration marker that shells out to the real binary.
